# Задание 05-02: добавление модели в каталог (CLI и dev-сервер)

## Сделать
1. Общая функция `addToCatalog(model, {id?, overwrite?, dry?})`: валидирует (validateAsset + требования каталога), приводит id к виду `[a-z0-9-_]` (транслит кириллицы допустим), при занятом id добавляет суффикс _2 (или перезаписывает при overwrite), пишет catalog/<id>.json (UTF-8, 2 пробела), обновляет index.json. Возвращает {ok, id, errors, warnings}.
2. CLI: `npm run catalog:add -- <файл|-> [--id slug] [--overwrite] [--dry]` (терпимо достаёт JSON через extractJson). При ошибках: русский список и out/ai/model-fix-request.md (запрос «исправь ошибки, верни только JSON модели целиком»).
3. Dev-сервер Vite (небольшой плагин в vite.config без новых зависимостей): `GET /api/catalog` (индекс и модели), `POST /api/catalog/add` (тело {model, overwrite?}; тот же код addToCatalog). Безопасность: только localhost; запись только в catalog/; id по маске; тело до 2 МБ; пути из запроса не принимать. В production-сборке эндпоинтов нет.
4. Проверки без браузера: юнит-тесты addToCatalog (позитив, дубль id, overwrite, плохой id, нет license, обрезанный JSON, слишком большая модель), тест обработчика плагина на подделанных req/res (если без запуска сервера нельзя, статус «не проверено» и ручной шаг для владельца).

## Приёмка
Тесты PASS; повторный `catalog:add` того же файла не ломает каталог; `npm run check` PASS.

## Не делать
Не открывать порты наружу, не писать вне catalog/.
