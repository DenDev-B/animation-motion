# Задание 03-08: переходы между сценами (движок, экспорт, контактный лист)

## Решение по модели времени (зафиксировано)
Переход = НАЛОЖЕНИЕ. Сцена i (i >= 1) с `transition.duration = d` начинается на d секунд раньше конца предыдущей: в течение этих d секунд обе сцены рендерятся каждая в своём локальном времени и смешиваются. Общая длительность проекта = сумма длительностей сцен минус сумма d всех переходов. Ограничение: 0 <= d <= min(duration[i-1], duration[i]) / 2.

## Контракт
`Scene.transition?: { type: 'cut'|'fade'|'crossfade'|'slide'|'wipe'|'dip', duration?: number (сек, для cut игнорируется), dir?: 'left'|'right'|'up'|'down', color?: string (для dip/fade, по умолчанию #000) }`.
- `fade` = затухание предыдущей сцены в color, затем появление новой без наложения кадров (внутри d: первая половина гасит предыдущую, вторая проявляет новую; фактически наложение времени сохраняется, но кадры сцен не смешиваются).
- `crossfade` = линейное смешение двух кадров.
- `slide` = новая сцена наезжает, старая уезжает (dir).
- `wipe` = шторка (dir).
- `dip` = через цвет (как fade, но симметрично).
Easing: sine, одинаковый для всех типов.
