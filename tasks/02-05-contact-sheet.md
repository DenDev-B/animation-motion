# Задание 02-05: контактный лист ролика для проверки без плеера

## Цель
Один PNG показывает весь ролик: можно проверить результат глазами без просмотра MP4. Это основа будущего «критика по картинке».

## Сделать
1. tools/contact-sheet.ts и npm script `contact`: аргументы `--project path`, `--step 0.5` (секунд между кадрами), `--cols 6`, `--thumb 320` (ширина миниатюры).
2. Кадры рендерятся тем же renderFrame на @napi-rs/canvas, без ffmpeg и без браузера.
3. На каждой миниатюре подпись: время от начала ролика (мм:сс.с) и имя сцены; на границе сцен рамка другого цвета.
4. Если листов больше 60 кадров, разбить на несколько файлов out/contact/<имя>_1.png, _2.png.
5. Опционально: `--at 5.0,12.5` выводит отдельные кадры в полном размере.

## Критерии приёмки
- Для whale-demo.project.json получается лист; число миниатюр = ceil(общая длительность / step); границы сцен видны.
- Повторный запуск даёт побайтно тот же PNG (воспроизводимость).
