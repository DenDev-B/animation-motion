# Задание 02-02: редактор: сохранить/открыть проект, вкладки сцен

## Цель
В editor/ работать с ProjectV1: открыть, сохранить, переключать сцены вкладками, управлять списком сцен.

## Сделать
1. Состояние редактора = ProjectV1 (один объект) + индекс активной сцены. Превью рисует активную сцену через renderFrame, как сейчас.
2. Меню «Файл»: Новый проект, Открыть (input type=file, .json, проверка validateProject, при ошибках показать список на русском и не загружать), Сохранить (скачивание .json через Blob; имя файла = title).
3. Панель вкладок сцен: переключение, «+» добавить пустую сцену (из шаблона минимальной валидной сцены), дублировать (новые уникальные id сцены; id внутри сцены можно оставить), удалить (запрещено удалять последнюю), переименовать (двойной клик), изменить порядок (кнопки ← → на вкладке; drag по желанию, если не больше 40 строк).
4. Под превью показать общую длительность проекта и длительность активной сцены.
5. Выбор формата проекта 16:9 / 9:16 и fps (24/30/60) в панели проекта.
6. Все строки UI на русском.

## Критерии приёмки
- Открыть projects/whale-demo.project.json, переключить вкладки, сохранить, открыть сохранённый файл: проект идентичен (JSON.stringify совпадает).
- Невалидный файл не ломает редактор, показывает причину.
- npm run build и typecheck проходят; check:project проходит.

## Проверка
Скриншоты через Node/@napi-rs/canvas не нужны: UI проверяет владелец. Агент обязан в отчёте написать, что UI «реализован, не проверен глазами», и перечислить ручной чек-лист из 6 шагов для владельца.
