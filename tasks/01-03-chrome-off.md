# Задание 01-03: убрать Chrome из обычной работы

## Цель
Владелец работает в обычном Chrome (личный и рабочий профили). Любой запуск Chrome или завершение процессов недопустим. Основной экспорт и сверка идут через Node (@napi-rs/canvas). Chrome остаётся запасным путём только по явному разрешению.

## Сделать
1. Эталон M0: 6 кадров M0 из out/compare скопировать в reference/m0/baseline/ (убрать из .gitignore только эту папку, остальное в out/ игнорировать). Если кадров нет, Chrome НЕ запускать, написать, чего не хватает.
2. compare-frames: по умолчанию сравнивает Node-рендер с reference/m0/baseline/. Режим с Chrome только при ALLOW_CHROME=1.
3. check-render (selftest воспроизводимости): по умолчанию через Node. Браузерная часть только при ALLOW_CHROME=1. Без переменной такие скрипты завершаются с понятным сообщением и кодом 0.
4. npm-скрипты: всё, что запускает Chrome, переименовать с суффиксом :chrome. `npm run check` их не вызывает.
5. AGENTS.md и PROJECT_RULES.md: агент не запускает браузеры и не завершает процессы (по имени или PID), если в задании нет явного разрешения. taskkill, pkill, killall, Stop-Process по имени образа запрещены всегда.
6. Аудит: найти все taskkill, pkill, killall, Stop-Process, process.kill, kill( и места запуска Chrome. Таблица «файл:строка, что делает, опасно ли».

## Критерии приёмки
- typecheck, build, check:schema, `npm run check`, compare:frames проходят при закрытом Chrome.
- Ни один скрипт без ALLOW_CHROME=1 не запускает браузер.

## Не делать
Не запускать Chrome ни для проверки, ни для замеров. Не добавлять зависимости. Не менять engine/.
