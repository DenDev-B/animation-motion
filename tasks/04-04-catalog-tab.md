# Задание 04-04: вкладка «Каталог» в редакторе

## Цель
Интерфейс минимальный и рабочий. Главное: список, превью, добавить в сцену, вставить новую модель JSON и сохранить в каталог.

## Сделать
1. Вкладка/панель «Каталог»: список моделей (из GET /api/catalog), поиск по названию и тегам, фильтр по виду. Строка: превью-миниатюра (рендер через общий код), название, теги, размер в метрах.
2. Превью выбранной модели на холсте: выбор позы или клипа, ползунок времени и кнопка «Играть» (клип по периоду).
3. Кнопки: «Добавить в сцену» (создаёт объект kind asset в выбранном слое через applyChange, c уникальным id, params.sizeM из realSize если сцена имеет world.unitsPerMeter, иначе без sizeM; clip по умолчанию, если у модели один клип), «Копировать JSON модели», «Копировать промт: изменить эту модель» (buildModelPrompt из 04-05, если уже есть; иначе общий buildPrompt с объяснением, что нужно вернуть модель целиком).
4. Блок «Новая модель»: поле «Вставить JSON модели» + кнопка «Проверить» (ошибки по-русски, предупреждения, кнопка «Копировать запрос на исправление») + кнопка «Сохранить в каталог» (POST /api/catalog/add; при занятом id вопрос «Перезаписать или добавить с суффиксом»). После сохранения список обновляется без перезагрузки страницы.
5. Блок «Промт для новой модели» (поля: описание, вид, позы через запятую, размер в метрах, стиль) + «Копировать промт»: подключается в 04-05 (если 04-05 не выполнено, поле неактивно и подписано «после 04-05»).
6. Строки на русском. Новые npm-зависимости и фреймворки запрещены. Без запуска браузера: статус UI «не проверено», в отчёте ручной чек-лист владельца (8 шагов: открыть вкладку, найти кита, превью клипа «плыть», добавить в сцену, сохранить проект, вставить тестовую модель-рыбу из docs, увидеть её в списке, добавить в сцену и экспортировать).

## Приёмка
typecheck, build, `npm run check` PASS; логика (формирование объекта сцены, фильтр списка, применение через applyChange с undo) вынесена в чистые функции и покрыта тестами без браузера.

## Не делать
Не менять engine/ кроме вынесения общей функции превью, если понадобится (описать в отчёте). Не добавлять зависимости.
