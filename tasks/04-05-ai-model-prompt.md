# Задание 04-05: промт для создания моделей любым ИИ

## Цель
Владелец пишет «собака, вид сбоку, три позы: стоит, идёт, бежит», копирует промт в любой ИИ, вставляет ответ в приложение. Никаких обращений к сервисам из кода.

## Сделать
1. `engine/ai-model.ts` (чистые функции): 
   - `buildModelPrompt({ description, view, poses: string[], sizeM?, style?, extraRules? })` возвращает текст: роль («художник-генератор моделей для JSON-формата»), краткий справочник формата модели из spec (части points/d, позы, клипы, meta, слоты палитры с их назначением: небо, свет, тело, брюхо, глаз, тень и т.д. по реальному списку из spec), жёсткие правила (одна модель = один JSON; ответ только JSON без комментариев и без текста вокруг; координаты в пределах bounds, центр примерно в (0,0); закрытые контуры; НЕ БОЛЕЕ 25 частей и 60 точек на часть; во всех позах число точек каждой части ровно то же, что в базовой; названия частей латиницей в id и по-русски в name; цвета только слотами палитры или hex; license.name = "own"; realSize в метрах; позы называются так, как просил владелец; клип «цикл» по позам с period 0.6–2.4 с), два коротких образца (рыба из 2 поз с клипом и небольшой «человечек» из частей), строка задачи с описанием.
   - `buildModelFixRequest(json, errors)`: «исправь ошибки, верни только JSON модели целиком».
   - `buildModelEditPrompt(model, task)`: «измени эту модель» с текущим JSON.
2. CLI: `npm run ai:model-prompt -- --description "..." --view side --poses "стоит,идёт,бежит" --size-m 0.6 [--style "..."]` пишет out/ai/model-prompt.md. `ai:model-apply` = `catalog:add --dry` + при ошибках model-fix-request.md.
3. Подключить в вкладку каталога (если 04-04 уже выполнено): блок «Промт для новой модели» активен и использует эти функции.
4. `check:model-roundtrip` (в `npm run check`): промт содержит справочник и образцы; ответ с обёрткой ```json проходит dry-add; ответ с разными длинами points в позах даёт ошибку с путём и fix-request; обрезанный ответ даёт ошибку «обрезан»; размер промта не более 14 КБ.

## Приёмка
`npm run check` PASS, документ docs/AI-MODELS.md (одна страница: как заказать модель у ИИ, как вставить, как исправить ошибки, типичные проблемы) создан.

## Не делать
Не подключать ИИ-сервисы и ключи. Не менять формат модели (это 04-01).
