# Задание 03-06: метры и эталоны масштаба

## Цель
Размер объектов в метрах, чтобы «кит рядом с человеком» был правдоподобным. Сцена остаётся в условных единицах (высота кадра 1000); метры вводятся поверх.

## Сделать
1. Схема (необязательные поля): `scene.world?: { unitsPerMeter: number }` (> 0); у CatalogAsset `realSize?: { heightM?: number; widthM?: number }` (> 0, хотя бы одно); у объекта kind=asset необязательный `params.sizeM` (метры по высоте asset: рендер масштабирует asset так, чтобы bounds-высота = sizeM * unitsPerMeter; если нет world, ошибка валидатора).
2. engine/units.ts: `unitsPerMeter(scene)`, `metersToUnits`, `unitsToMeters`, `assetScaleForMeters(asset, sizeM, scene)`. Чистые функции с юнит-тестами.
3. Эталоны каталога (силуэты кодом, простые части в SVG-путях, слоты цвета): `catalog/human.json` (realSize.heightM 1.75), `catalog/house.json` (двухэтажный дом, 7 м), `catalog/plane.json` (пассажирский самолёт сбоку, ширина (длина) 37 м, высота 12 м). У `catalog/whale.json` добавить `realSize` (горбатый кит, длина ≈ 15 м; запиши в отчёт, какое значение поставил и почему).
4. Фикстура scenes/fixtures/scale-compare.json: человек, дом, кит, самолёт рядом на одной оси с подписями (kind=text) «1,75 м», «7 м», «15 м», «37 м». world.unitsPerMeter подобрать так, чтобы всё влезло (запиши значение).
5. Проверки: отношение высоты bounds, нарисованной в кадре, к сумме метров совпадает с ожидаемым в пределах 1% (измерение через расчёт масштаба, а не по пикселям); человек/кит по длине 1.75 : 15 ≈ 1 : 8.57.

## Приёмка
M0 6/6 EXACT; все проверки PASS; контактный лист scale-compare создаётся. Старые сцены без world рендерятся как раньше.

## Не делать
Не менять смысл существующих координат. Не вводить метры как обязательные.
