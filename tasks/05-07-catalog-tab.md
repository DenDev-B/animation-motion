# Задание 05-07: вкладка «Каталог» в редакторе

## Цель
Минимальный рабочий интерфейс: найти модель, посмотреть, добавить в сцену, загрузить новую (JSON или SVG).

## Сделать
1. Вкладка «Каталог»: список из GET /api/catalog, поиск по названию и тегам, фильтр по виду. Строка: миниатюра (общий рендер), название, теги, размер в метрах, лицензия.
2. Превью модели на холсте с выбором пресета движения (walk, run, fly, swim, hop, sway, без) и ползунком времени/«Играть».
3. Кнопки: «Добавить в сцену» (объект kind asset в выбранный слой через applyChange, уникальный id, sizeM из realSize при наличии world.unitsPerMeter), «Копировать JSON модели», «Копировать промт: изменить эту модель» (общий buildPrompt с пояснением вернуть модель целиком).
4. Блок «Новая модель из JSON»: поле вставки, «Проверить» (ошибки по-русски, предупреждения, кнопка «Копировать запрос на исправление»), «Сохранить в каталог» (POST /api/catalog/add; при занятом id вопрос «перезаписать или суффикс»).
5. Блок «Импорт SVG»: выбор файла (input type=file), поля id, название, вид, размер в метрах, ось размера, теги, лицензия, автор, источник, ссылка, галочка «указывать автора»; «Импортировать» отправляет на POST /api/catalog/import-svg (dev-сервер использует importSvg из 05-03 и addToCatalog), показывает warnings; список обновляется без перезагрузки.
6. Блок «Промт для новой модели через ИИ»: поля описание, вид, размер; «Копировать промт» (buildModelPrompt: справочник формата моделей, правила (не более 25 частей, 60 точек на часть, закрытые контуры, слоты палитры или hex, license.name = "own"), образец, описание). Чистая функция в engine/ai-model.ts + тест, что промт ≤ 14 КБ, а ответ в ```json проходит `catalog:add --dry`.
7. Список «Титры проекта»: кнопка «Показать/Копировать титры» (collectCredits).
8. Строки на русском. Новых зависимостей и фреймворков нет. UI в браузере агент не проверяет: статус «не проверено», в отчёте ручной чек-лист из 8 шагов для владельца.

## Приёмка
typecheck, build, `npm run check` PASS; логика (фильтр списка, формирование объекта сцены, применение с undo) в чистых функциях с тестами.
