# Задание 03-02b: kind `shape` — рисунок прямо в сцене (инлайн-модель)

## Цель
ИИ (или владелец) должен уметь нарисовать ЛЮБОЙ объект (солнце, луну, звезду, корабль, облако особой формы) прямо в JSON сцены без нового кода движка. Луна и солнце здесь только примеры.

## Контракт
`kind: "shape"`, `params.model` = модель в том же формате, что CatalogAsset (bounds, parts с path/line/circle, off, fill, rim, stroke, anim частей), id/name/version необязательны. Остальные поля объекта (x,y,s,rot,alpha,color,anim,partAnim) работают как у `asset`. Цвета частей: hex или слоты палитры. Рендер идёт через тот же drawAsset, что и у asset (никакого второго рендера).

## Сделать
1. Тип, spec-описание (engine/spec.ts), валидатор (через validateAsset), рендер: ветка shape вызывает drawAsset с inline-моделью. Кэш по хэшу модели.
2. Фикстуры-примеры (scenes/fixtures/): `shape-sun-moon.json`: солнце (круг + лучи), луна-диск с серпом (две дуги/круга), звезда-пятиконечная (path), маленький кораблик (path); в 16:9 и 9:16. Пример должен читаться человеком и ИИ: короткие осмысленные id частей.
3. Проверка эквивалентности: копия `catalog/whale.json`, вставленная как `shape` с теми же параметрами, рендерится побайтно так же, как `asset: whale` (EXACT).
4. В `docs/SCHEMA-v1.md` (генератор из 03-02) добавить раздел «Нарисовать своё через shape» с двумя примерами (круг и path).
5. Проверка круга с ИИ: `ai:prompt` для shape-sun-moon.json с задачей «добавь кольцо вокруг луны» содержит справочник по shape.
