# Задание 03-09: редактор: добавление объектов, переходы, пресеты камеры

## Цель
Новые возможности этапа 3 доступны из интерфейса без ручной правки JSON.

## Сделать
1. Панель «Добавить объект»: выпадающий список kind (sky, glow, cloud, skyline, asset, mountains, hills, stars, moon, rain, snow, birds, text, counter) + выбор слоя (или «новый слой» с depth). Вставляется объект с значениями по умолчанию из контрактов этапа 3, уникальным id и понятным именем по-русски. Для asset: выбор модели из каталога (включая human, house, plane, whale).
2. Панель свойств активного объекта: числовые поля и выбор цвета (слот палитры или hex) для params нового kind, с границами из валидатора; изменения идут через applyChange (чтобы работали отмена и автосохранение). Если полей слишком много, допустим режим «JSON объекта» с проверкой, но основные параметры (seed, count, size, color, text, from/to) должны быть полями.
3. Вкладка сцены: выбор перехода в следующую сцену (тип, длительность, направление, цвет); сразу показывать итоговую длительность проекта с учётом наложения.
4. Камера: кнопка «пресет камеры» (push-in, pull-out, pan-left, pan-right, drift) подставляет ключи через cameraPreset; поля тряски (amp, freq, t0, t1, seed).
5. Превью перехода: при перемотке на момент перехода показывать композицию (через compose.ts).
6. Все строки на русском. Автосохранение и история работают для всех новых действий.

## Приёмка
- typecheck, build, check, check:history PASS; в history-тесты добавить сценарий «добавить объект → undo → redo» на уровне функций без браузера.
- UI глазами не проверяется агентом: статус «не проверено» и ручной чек-лист из 8 шагов для владельца в отчёте (добавить звёзды, добавить луну, дождь, текст, счётчик, переход crossfade, пресет push-in, тряска; затем сохранить, перезагрузить, экспортировать).

## Не делать
Не запускать браузер. Не добавлять фреймворки и зависимости. Не менять engine/ (если нужна правка, остановись и опиши какая).
