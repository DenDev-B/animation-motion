# Задание 05-05: пресеты движения для любого объекта

## Цель
Импортированный силуэт должен «жить» без ручных поз: шагает, бежит, летит, плывёт, прыгает, покачивается.

## Контракт
`params.motion?: { preset: 'walk'|'run'|'fly'|'swim'|'hop'|'sway'; speed?: number (0.2..4, по умолчанию 1); amp?: number (0..3, по умолчанию 1); phase?: number (0..1, 0); dir?: -1|1 (по умолчанию 1: куда повёрнут объект) }` для kind asset и shape (и кинд, где применимо). Допускается массив из нескольких (суммируются).

## Реализация
Чистая функция `motionTransform(motion, t, objectScale) -> { dx, dy, rot, sx, sy }` в engine/motion.ts. Примерные формулы (подобрать, чтобы выглядело живо, фиксировать константы в spec):
- walk: период шага 0.7/speed с; вертикальное подпрыгивание 2 раза за цикл на amp·0.012·высота; небольшой наклон ±1.5° с частотой шага.
- run: период 0.45/speed; подпрыгивание amp·0.03·высота; наклон вперёд 6° + колебание ±2.5°.
- fly: плавание по Y (период 3/speed, amp·0.03·высота), «взмах» через вертикальное сжатие sy = 1 − 0.12·amp·|sin| с периодом 0.5/speed, лёгкий крен ±4°.
- swim: волна вдоль тела через поворот ±5° (период 1.8/speed) и сдвиг dy период 3.6/speed amp·0.015·высота.
- hop: серия прыжков: парабола высотой amp·0.25·высота, период 1.2/speed, сжатие при приземлении sy 0.92 на 0.1 цикла.
- sway: маятник ±amp·6° период 4/speed вокруг нижней точки bounds (pivot снизу).
Порядок применения: motion после anim объекта, до рендера, детерминированно по t (никакого накопленного состояния). Движение вперёд (по оси X) задаётся обычным `anim: move`, пресет его не заменяет.

## Сделать
1. Типы, spec, валидатор (диапазоны, массив), рендер, юнит-тесты motionTransform (периодичность, нулевая амплитуда даёт тождество, независимость от порядка кадров, фаза).
2. Фикстуры scenes/fixtures/motion-presets.json: по одному объекту на пресет (используй существующие модели каталога и shape-фигуры, например человек, кит, птица из shape), 16x9 и 9x16, контактные листы.
3. Документация в docs/SCHEMA-v1.md (генератор) с коротким описанием каждого пресета на русском.
