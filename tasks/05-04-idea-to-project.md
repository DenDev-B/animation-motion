# Задание 05-04: промт «идея → проект из нескольких сцен»

## Цель
Главная фича комбайна: владелец пишет идею, копирует промт в любой ИИ, вставляет ответ, получает готовый проект из нескольких сцен, где объекты берутся из каталога, а недостающие ИИ рисует через shape.

## Сделать
1. `engine/ai-project.ts` (чистые функции): 
   - `buildProjectPrompt({ idea, format?: '16:9'|'9:16', fps?, scenes?: number (2..12, по умолчанию 5), sceneSeconds?: number (4..20, по умолчанию 8), tone?, catalogIndex })`. Текст: роль («сценарист-режиссёр и редактор JSON-проектов»), краткий справочник формата из spec (проект, сцена, kind, params с диапазонами, motion-пресеты, переходы, камера, world.unitsPerMeter и sizeM), жёсткие правила (ответ только одним JSON проекта; уникальные id сцен, слоёв, объектов; одна палитра на сцену с настроением; в каждой сцене небо и фон, 1–3 смысловых объекта, камера с лёгким движением; масштаб в метрах через world.unitsPerMeter и sizeM; объекты из каталога по id; чего нет в каталоге рисовать через kind shape простыми контурами и ПРЕДЛОЖИТЬ в поле meta.suggestions проекта список недостающих моделей (id, описание) для добавления в каталог; переходы между сценами из списка; счётчики и текст титров по идее; без случайности кроме seed), блок «Доступные модели каталога» (из индекса: id, name, tags, view, realSize), сама идея. Размер промта не более 20 КБ.
   - Допускается необязательное поле проекта `meta?: { suggestions?: { id: string, description: string, view?: string, sizeM?: number }[] }` (описать в spec, валидатор: не ошибка, если нет).
2. CLI: `npm run ai:project-prompt -- --idea "текст" [--scenes 5] [--scene-seconds 8] [--format 16:9] [--fps 30]` пишет out/ai/project-prompt.md. `npm run ai:apply -- <ответ> --new [--name slug]` (расширение существующего ai:apply) создаёт projects/<slug>.project.json (не затирая существующий, суффикс _2), валидирует; при ошибках fix-request. Если у ответа есть meta.suggestions, печатает список «Предложено добавить в каталог».
3. Редактор: в JSON-панели блок «Новый проект из идеи»: поля «Идея», «Сцен», «Секунд на сцену», кнопка «Копировать промт»; область вставки ответа и «Создать проект» (проверка с ошибками по-русски и кнопкой «Копировать запрос на исправление»; замена текущего проекта через applyChange с подтверждением, undo работает). UI минимальный, статус «не проверено» и чек-лист владельца в отчёте.
4. Пример ответа: docs/examples/project-reply-example.json: проект из 3 сцен по идее «Что если бы киты летали над городом», написанный агентом строго по правилам промта (в роли ИИ), с одной недостающей моделью в suggestions и одним shape. Тест `check:project-roundtrip` (в `npm run check`): промт содержит каталог и справочник и укладывается в 20 КБ; пример ответа проходит `ai:apply --new` в temp-каталог; обрезанный ответ даёт ошибку «обрезан»; пример с неверным диапазоном даёт fix-request.
5. docs/AI-GUIDE.md (одна страница на русском): как сделать ролик за 5 шагов (идея → промт → ИИ → применить → правки через «Копировать для ИИ» → экспорт).

## Приёмка
`npm run check` PASS; пример проекта экспортируется (короткий экспорт 3 с на сцену не нужен, достаточно контактного листа и ffprobe на полном экспорте); SHA whale-demo прежний.

## Не делать
Не подключать ИИ-сервисы и ключи. Не менять схему сцены сверх необязательного meta проекта.
