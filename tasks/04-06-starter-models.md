# Задание 04-06: стартовые модели через круг ИИ и демо-проект

## Цель
Проверить на практике, что круг «промт → модель → каталог → ролик» работает, а не только пишется.

## Сделать
1. Через `ai:model-prompt` собрать промты на две модели: «собака, вид сбоку, позы: стоит, идёт, бежит, размер 0.6 м по высоте» и «птица, вид сбоку, позы: крылья вверх, крылья вниз, размер 0.4 м по ширине». Агент играет роль ИИ из промта: сам пишет JSON моделей строго по правилам промта (не обходя валидатор), добавляет через `catalog:add` (ошибки чинит по fix-request). Качество рисунка простое (силуэты), главное формат и анимация. Сохранить промты и ответы в docs/examples/ (model-prompt-dog.md и т.д.), чтобы владелец мог повторить с любым другим ИИ и сравнить.
2. Фикстура scenes/fixtures/catalog-demo.json и проект projects/catalog-demo.project.json (2 сцены, 8 с каждая): первая сцена: дневной город (skyline), по земле идёт собака (клип «идёт», движение move слева направо), в небе стая птиц из модели bird (клип «взмах»), кит из каталога высоко, масштаб: человек, собака и кит в метрах правдоподобно; вторая сцена: ночь, собака бежит (клип «бежит»), кит.
3. Экспорт 16x9 и 9x16 (preset veryfast, crf 18), контактные листы, ffprobe PASS, время/память в отчёт.
4. Обновить PROJECT_STATE.md (раздел «Сейчас»: этап 4 завершён, ждёт приёмки глазами; «Следующий шаг»: этап 5 конвертер SVG → модель; зафиксировать решения этапа 4) и docs/ARCHITECTURE.md (каталог, позы, клипы, круг ИИ).
5. Итоговый `npm run check` целиком; общий отчёт docs/reports/stage4.md.

## Приёмка
Все проверки PASS, MP4 открываются обычным проводником, SHA whale-demo прежний, в отчёте ручной чек-лист владельца: посмотреть MP4 и контактные листы, повторить промт на собаку с любым внешним ИИ, вставить ответ в «Новая модель», сохранить, добавить в сцену.

## Не делать
Не менять формат модели ради красоты рисунка. Если рисунок плохой, записать замечания в отчёт, исправление это отдельное задание.
