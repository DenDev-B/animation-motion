# Задание 02-04: экспорт всего проекта в MP4

## Цель
tools/export.ts умеет рендерить ProjectV1: все сцены подряд в один MP4, с правильным числом кадров. Одиночная сцена продолжает работать.

## Сделать
1. Аргументы: `--project projects/whale-demo.project.json` (новый путь) и прежний путь для одной сцены. Формат и fps берутся из проекта; можно переопределить флагами `--format`, `--fps`.
2. Общий цикл кадров: глобальный индекс g = 0..N-1, где N = projectFrameCount(project); locateFrame(g) даёт сцену и локальное t. Один холст и один буфер, один ffmpeg на весь ролик (как сейчас, rawvideo в stdin).
3. Каталог моделей загружается один раз; валидация проекта через validateProject перед стартом, при ошибках выход с кодом 1 до запуска ffmpeg.
4. Прогресс каждые 30 кадров: кадр g/N, сцена, мс/кадр, оценка оставшегося времени.
5. Приёмка ffprobe: кодек h264, yuv420p, нужный fps, число кадров = N, длительность = N/fps (допуск 1 кадр), разрешение по формату. Отчёт PASS/FAIL с причиной.
6. Выход в out/export/<имя-проекта>_<format>.mp4. Существующий файл не затирать молча: добавить суффикс _2, _3 или флаг --overwrite.
7. Не менять механизм кадра: кадр = чистая функция renderFrame(ctx, scene, t, size, env).

## Критерии приёмки
- Для projects/whale-demo.project.json в обоих форматах: ffprobe PASS, число кадров совпадает с projectFrameCount.
- Первый кадр второй сцены побайтно совпадает с кадром t=0 этой же сцены, отрисованным отдельным экспортом одной сцены (проверка в скрипте, EXACT).
- Время и пик памяти в отчёте.
