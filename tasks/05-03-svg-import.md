# Задание 05-03: импорт SVG в каталог

## Цель
Взять SVG из бесплатного набора (например, силуэт животного, здание, транспорт), превратить в модель каталога с лицензией и автором. Без новых зависимостей.

## Сделать
1. `engine/svg-import.ts` (чистые функции, без DOM; разбор XML собственным минимальным токенизатором): 
   - поддерживаемые элементы: `svg` (viewBox, width/height), `g`, `path`, `circle`, `ellipse`, `rect` (с rx/ry), `polygon`, `polyline`, `line`; атрибуты fill, stroke, stroke-width, opacity, fill-opacity, transform (translate, scale, rotate, matrix, skewX/skewY, цепочки), style="fill:...;stroke:..." и цвета: `#rgb/#rrggbb`, `rgb()`, именованные базовые цвета, `none`, `currentColor` (считать как заданный параметром `--color`, по умолчанию #222222).
   - path: полный разбор команд M L H V C S Q T A Z в абсолютных и относительных вариантах; дуги A переводятся в кубические Безье; трансформации применяются к точкам (результат пишется как абсолютные команды M/L/C/Z); скругление чисел до 2 знаков.
   - неподдерживаемое (image, text, filter, mask, clipPath, use/symbol, градиенты, pattern) не ломает импорт: игнорируется с предупреждением в список warnings (градиент заменяется цветом первой остановки с предупреждением).
2. Нормализация: bounds вычисляются по реальному ограничивающему прямоугольнику геометрии; центр переносится в (0,0); масштаб подбирается так, чтобы высота bounds была 200 единиц (параметр `--scale-height`), пропорции сохраняются; ось Y как в движке (проверить по существующим моделям и сохранить сходство ориентации: SVG Y вниз).
3. Части: одна часть на каждый path/фигуру, id `p1`, `p2`… (или из id/class элемента, если он валиден), name по-русски «Часть N», fill: исходный цвет; режимы `--colors keep|mono|slots` (keep: hex как есть; mono: все части одним цветом, слот `body`; slots: до 4 самых частых цветов получают слоты body, accent, dark, light по яркости, остальные hex). Лимит: до 200 частей, до 200 КБ данных путей, иначе ошибка с советом упростить.
4. CLI: `npm run catalog:import-svg -- <файл.svg> --id dog --name "Собака" --view side --facing right --size-m 0.6 [--size-axis height|width] --tags "dog,animal,собака" --license "CC BY 3.0" --author "Имя" --source "game-icons.net" --url "https://..." --attribution true [--colors keep] [--dry]`. Формирует модель и передаёт в addToCatalog (05-02). Обязательны --id, --view, --size-m, --license; без них понятная ошибка.
5. Тестовые SVG (оригинальные, нарисованные агентом, лицензия own): tests/svg/ с 6 файлами: простой path, path с относительными командами и дугами, группа с transform=matrix, circle+rect+polygon, style="..." цвета, файл с градиентом и текстом (проверка предупреждений). Для каждого: импорт, валидация модели, рендер кадра через shape/asset, SHA кадра воспроизводим.
6. Проверка дуг: путь с дугой после импорта визуально (по SHA и по контрольным точкам: заданный круг как две дуги даёт точки на окружности с допуском 0.5%) совпадает с кругом.
7. Фикстура scenes/fixtures/svg-import-demo.json: импортированные модели на сцене; контактные листы 16x9 и 9x16.
