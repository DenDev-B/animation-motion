# Очередь заданий (этап 1 хвост и этап 2)

Порядок: 01-03 → 02-01 → 02-02 → 02-03 → 02-04 → 02-05.
Зависимости: 02-02 и 02-04 требуют 02-01; 02-03 требует 02-02; 02-05 требует 02-01.
Параллельно можно: 02-04 и 02-05 после 02-01 (но один агент делает по одному).

Каждое задание: один коммит, push делает владелец. Агент пишет статусы: сделано / запущено и проверено / не проверено.
Общие запреты: Chrome и браузер не запускать, процессы не убивать, зависимости не добавлять, engine/ без DOM и без Math.random/Date.now/performance.now.
Промт агенту для любого задания: «Прочитай AGENTS.md, PROJECT_RULES.md и tasks/<файл>. Выполни задание строго по нему, один коммит, честные статусы в отчёте.»
