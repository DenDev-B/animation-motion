# Очередь этапа 4 «Формат модели + каталог» (04-00 → 04-06)

Цель владельца: персонажи и объекты (кит, собака, птица…) добавляются в приложение ОДИН РАЗ через каталог и переиспользуются в любых роликах. Модель создаёт любой ИИ по промту из приложения или владелец руками. Поле для вставки JSON модели есть в интерфейсе.

## Решения архитектора (окончательные)
- Формат модели = расширение существующего CatalogAsset (тот же формат, что у `kind: asset` и `kind: shape`). Старые модели (whale и др.) остаются валидными и рендерятся побайтно как раньше. Все новые поля необязательные.
- Форма части: либо SVG-путь `d` (как сейчас), либо набор точек `points`. Позы = альтернативные положения (набор точек одинаковой длины и/или смещение/поворот/масштаб частей). Переход между позами = линейная интерполяция, детерминированная.
- Клип = цикл по позам, функция от времени сцены.
- Кости не вводим (позже, если понадобится). Меши и glTF в этап 9, в формате оставить только поле-заготовку `mesh?: unknown` без реализации и без валидации содержимого.
- Каталог принадлежит приложению: папка `catalog/`, общий для всех проектов. Проекты ссылаются на модели по id. Встроенные в сцену `assets` остаются как переопределение (совместимость).
- Запись в каталог из интерфейса идёт через dev-сервер Vite (небольшой плагин без новых зависимостей), работает только на localhost и только внутри папки `catalog/`.
- Никаких обращений к ИИ-сервисам: только текст туда и обратно (как в круге сцен).

## Общие правила (на каждое задание)
- Прочитай AGENTS.md, PROJECT_RULES.md, docs/SCHEMA-v1.md, tasks/<файл>. Один коммит на задание: "<номер>: <кратко по-русски>". Push не делать.
- Браузер и Chrome не запускать, процессы не завершать (run.bat и stop.bat принадлежат владельцу, не трогать), зависимости не добавлять.
- Перед коммитом: typecheck, build, `npm run check` и проверки задания. Красное не коммитить; после двух неудачных попыток остановиться на задании и не браться за зависимые.
- Если задание расходится с реальным кодом, мелкое решай разумно и записывай в отчёт; крупное (нужно менять поведение старых сцен, SHA, схему сцены) значит остановка.
- Старые сцены, проекты и SHA контактного листа whale-demo не меняются (кроме явно разрешённого в 04-00 пункта 2). M0 6/6 EXACT.
- Кириллица: файлы только UTF-8 без BOM; не использовать PowerShell-перенаправления для записи текста с русскими символами (` > file`), писать через Node/редактор.
- Описание формата вносить в engine/spec.ts и пересоздавать docs (`npm run docs:schema`), `check:docs` должен проходить.
- Статусы: «сделано» / «запущено и проверено» / «не проверено».
