# Задание 02-03: отмена/повтор и автосохранение

## Цель
Любая правка проекта обратима, закрытие вкладки не теряет работу.

## Сделать
1. editor/history.ts: стек снимков ProjectV1 (structuredClone), лимит 100, операции push(label), undo(), redo(), canUndo, canRedo. Серия быстрых однотипных правок (например, движение ползунка) схлопывается в один шаг (debounce 400 мс, только в editor/, Date.now там допустим).
2. Все изменяющие действия редактора идут через одну функцию applyChange(label, mutator), чтобы история и автосохранение не пропускали правки.
3. Кнопки Отмена/Повтор и горячие клавиши Ctrl+Z, Ctrl+Y, Ctrl+Shift+Z; не срабатывают, когда фокус в текстовом поле.
4. Автосохранение в localStorage (ключ animation-motion/autosave/v1) через 1 с после правки; при старте, если автосохранение новее открытого файла или файла нет, предложить «Восстановить прошлую сессию?». Весь доступ к localStorage в try/catch (может быть недоступен или пуст).
5. Индикатор «Сохранено / Есть несохранённые изменения» (имеется в виду скачанный файл), предупреждение при закрытии страницы с несохранёнными изменениями.

## Критерии приёмки
- Юнит-проверка history.ts без браузера (npm script check:history): 5 правок, 3 undo, 1 redo, новая правка после undo обрезает redo, лимит 100 соблюдается, снимки независимы (изменение нового не меняет старый).
- build и typecheck проходят.
- Ручной чек-лист для владельца в отчёте (правка → Ctrl+Z → Ctrl+Y → перезагрузка страницы → восстановление).
