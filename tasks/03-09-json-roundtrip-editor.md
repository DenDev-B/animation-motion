# Задание 03-09 (версия 2): редактор: JSON-круг и минимум интерфейса

## Цель
Интерфейс не приоритет. Нужно одно: в редакторе видеть JSON и гонять его через ИИ. Остальное (переходы, камера, объекты) правится в JSON.

## Сделать
1. Панель «JSON» с переключателем области: сцена / весь проект / выбранный объект. Показывает текущий JSON (форматированный, моноширинный, с номерами строк не обязательно).
2. Кнопки: «Копировать JSON»; «Копировать для ИИ» (buildPrompt из engine/ai-io.ts, строка задачи берётся из поля ввода рядом, может быть пустой); «Вставить ответ ИИ» (область для вставки, extractJson, валидация).
3. Результат вставки: при ошибках показать список по-русски (путь, что не так, допустимо) и кнопку «Копировать запрос на исправление» (buildFixRequest); при успехе кнопка «Применить» (замена выбранной области через applyChange, чтобы работали undo/redo и автосохранение) и список warnings.
4. Список «Шаблоны объектов»: для каждого kind из spec кнопка «Копировать пример» (минимальный валидный JSON объекта со значениями по умолчанию), чтобы вставить в промт или в сцену руками.
5. Строки на русском. Без новых фреймворков и зависимостей.

## Приёмка
- typecheck, build, `npm run check` PASS; history-тест «применить JSON → undo → redo» без браузера.
- UI глазами не проверяется агентом: статус «не проверено» и ручной чек-лист из 6 шагов для владельца в отчёте (открыть проект; Копировать для ИИ; вставить обратно без изменений: «ошибок нет»; вставить обрезанный JSON: понятная ошибка; вставить JSON с неверным числом: ошибка с путём и кнопка запроса на исправление; применить, затем Ctrl+Z).

## Не делать
Не запускать браузер. Не писать формы для каждого kind, переходов и камеры (откладывается). Не менять engine/ кроме ai-io.ts, если нужна правка: остановись и опиши.
