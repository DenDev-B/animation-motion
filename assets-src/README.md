# assets-src — папка с исходными SVG для импорта в каталог

Коложи сюда SVG-файлы и заполни `manifest.json` (или `manifest.example.json` как шаблон), затем импортируй одной командой:

```
npm run catalog:import-manifest -- assets-src/manifest.json
```

## Куда класть SVG
- `assets-src/own/` — твои собственные SVG (например, нарисованные вручную). Эти файлы отслеживаются в git.
- `assets-src/downloads/` — скачанные из бесплатных наборов. Папка по умолчанию не попадает в git (см. `.gitignore`). Перед использованием проверь лицензию на сайте источника.

## Поля манифеста
| Поле | Описание | Обязательно |
|------|----------|-------------|
| `file` | Путь к SVG относительно папки манифеста (например `own/tree-simple.svg` или `downloads/dog.svg`) | да |
| `id` | Идентификатор модели в каталоге (латиница, дефисы) | да |
| `name` | Человекочитаемое название | да |
| `view` | Вид модели: `side`, `front`, `top`, `bottom`, `three-quarter` | да |
| `facing` | Поворот: `left` или `right` | нет |
| `sizeM` | Размер в метрах (высота, или ширина если `sizeAxis: "width"`) | да |
| `sizeAxis` | `height` (по умолчанию) или `width` — какая сторона равна `sizeM` | нет |
| `tags` | Массив тегов для поиска в каталоге | нет |
| `license` | Лицензия: `own`, `CC0`, `CC BY 3.0`, `CC BY 4.0` и т.д. | да |
| `author` | Автор | нет |
| `source` | Источник | нет |
| `url` | Ссылка на источник | нет |
| `attribution` | Нужна ли ссылка на автора (`true`/`false`) | нет |
| `colors` | Режим цветов импорта: `keep`, `mono`, `slots` | нет |

## Лицензия
Перед добавлением скачанной модели проверь лицензию на сайте источника (CC0, CC BY 3.0/4.0, own и т.д.) и укажи её в поле `license` с указанием автора и источника. Собственные модели указывай как `own` без указания источника.

## Сухий прогон (без записи)
Чтобы проверить манифест без записи моделей, используй флаг `--dry`:

```
npm run catalog:import-manifest -- assets-src/manifest.example.json --dry
```

Записи с отсутствующими файлами выводятся как `пропущено: нет файла`, ошибка одной записи не останавливает остальные.
