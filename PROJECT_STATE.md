## Решения
- Первая тема канала: «Что если»; первый ролик про летающих китов. Один стиль на все сцены (силуэты, закат/ночь/рассвет палитрами).
- Графика кодом + каталог объектов (JSON), ИИ подключаем позже, ручной режим «копировать/вставить» остаётся навсегда.
- Бесплатные модели (Gemini, Groq) на старте; озвучка и тайминги откладываем до приемлемой сцены.
- Ракурсы снизу (кит снизу, небоскрёбы снизу) не в первом этапе.
- Стек: TypeScript + Vite, Node, ffmpeg; 3D (Three.js) в конце.
- Процесс: Claude тимлид (Custom instructions проекта), OpenCode исполнитель (AGENTS.md в корне); коммит делает агент, push владелец.
- Конвертер SVG → модель с костями и позами: в плане (этап 5), свой редактор точек откладывается.
- Идея на потом: эффект пересборки (объект распадается на части и собирается в другой).
- Рендер: `renderFrame(ctx, scene, t, size, env)`; engine/ не касается DOM, холсты через env.createCanvas, кэши через createRenderCache(). Кит живёт в catalog/whale.json, сцена ссылается на него по `asset: "whale"`.
- Dev-зависимости: vite, typescript, @types/node, puppeteer-core, pixelmatch, pngjs (+ типы). Новые только по согласованию.
- Этап 3: единственный источник контракта — `engine/spec.ts`; из него строятся валидатор, `docs/SCHEMA-v1.md` и ИИ-подсказка. Новое поведение — новые `kind` (stars/rain/snow/birds/text/counter/asset/shape), слой остаётся группой с `depth`.
- Луна и солнце — примеры через `shape.params.model`, отдельных kind нет. Модели каталога можно рисовать inline через `shape`.
- Переходы проектов: cut/fade/dip/slide/crossfade; переход принадлежит следующей сцене и перекрывает время; `locateFrame` возвращает пару кадров и прогресс.
- Метры: `world.unitsPerMeter` + `params.sizeM`; без `world` старые сцены рендерятся как раньше. Тряска камеры — `camera.shake` с окном и `decay: out`, пресеты в редакторе.
- JSON-круг: правка сцена/проект/объект, проверка, история undo/redo, «Копировать для ИИ» → вставка ответа → проверка → применение → запрос на исправление. Ручной режим остаётся основным.
- Демо 9:16: `camera.verticalFit` и глубины подобраны под вертикаль; полностью бесшовной раскладки из одного файла нет — сцена «Масштаб» сжата и центрирована (компромисс, см. отчёт).
