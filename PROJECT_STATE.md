## Решения
- Продукт: комбайн для многих роликов (идея → проект из нескольких сцен), не приложение для одного ролика. Кит только первая тема канала «Что если».
- Каталог моделей принадлежит приложению (папка catalog/), проекты ссылаются по id; недостающее ИИ рисует через kind shape; готовая графика берётся из бесплатных SVG-наборов с записью лицензии и автора (титры собираются автоматически).
- 2D силуэты и пути; позы/клипы, кости, меши и 3D отложены (этап 9, главный риск: 3D-рендер без экрана на Node).
- Интерфейс и шрифты вторичны; главное: JSON виден, копируется в любой ИИ и возвращается с проверкой и внятными ошибками.
- Документы формата генерируются из engine/spec.ts (`npm run docs:schema`, `check:docs`).
- Процесс: Claude тимлид (Custom instructions проекта), исполнитель сейчас Kimi Code desktop (бесплатный тариф, короткие сессии); один коммит на задание, push делает владелец; перед концом лимита агент сохраняет работу в ветку wip/<номер>.
- Исполнитель не запускает браузеры и не завершает процессы; run.bat/stop.bat принадлежат владельцу.
- Русский текст не писать через PowerShell-перенаправления (портит кириллицу; ловит `check:text`).
