# Схема сцены v1

Сцена — JSON с `version: 1`. Размеры задаются в условных единицах: высота кадра 1000, центр координат — середина, ось Y направлена вниз. Неизвестные поля сохраняются и выдаются как предупреждения.

## Поля сцены

| Поле | Тип / диапазон | По умолчанию | Описание |
|---|---|---|---|
| `version` | int; ≥1…≤1 | `1` | Версия формата сцены. |
| `title` | string; — | — | Название сцены. |
| `duration` | number; >0…∞ | — | Длительность в секундах; должна быть больше нуля. |
| `palette` | object; — | — | Цветовые слоты сцены. |
| `style` | object; — | `{}` | Эффекты изображения. |
| `camera` | object; — | — | Ключи движения камеры. |
| `assets` | object; — | — | Встроенные модели каталога. |
| `layers` | array; — | — | Слои сцены в порядке от дальнего к ближнему. |

## Палитра

Слоты: `sky`, `sun`, `haze`, `far`, `mid`, `near`, `whale`, `belly`, `rim`, `cloudLight`, `cloudShadow`, `window`. `sky` — массив минимум из двух цветов; остальные слоты — отдельные цвета. Цвета: `#rgb`, `#rrggbb` или `#rrggbbaa`.

Ключ камеры имеет поля `t`, `x`, `y`, `zoom`; время ключей должно возрастать, `zoom > 0`.

## Переходы проекта

Переход задаётся у сцены проекта, начиная со второй, и означает наложение: сцена начинается на `duration` секунд раньше конца предыдущей. Длительность проекта = сумма сцен минус сумма наложений; `duration` не больше половины меньшей из соседних сцен; у первой сцены допустим только `cut` (для него `duration` игнорируется).

| Поле | Тип / диапазон | По умолчанию | Описание |
|---|---|---|---|
| `type` | enum; cut · fade · crossfade · slide · wipe · dip | `"cut"` | Тип перехода между соседними сценами. |
| `duration` | number; ≥0…∞ | — | Длина наложения в секундах; для cut игнорируется. |
| `dir` | enum; left · right · up · down | `"left"` | Направление для slide и wipe. |
| `color` | color; — | `"#000"` | Цвет для fade и dip. |

## Нарисовать своё через shape

`kind: "shape"` рисует модель прямо в сцене: `params.model` содержит `bounds` и `parts` в формате каталога; `id`, `name` и `version` модели необязательны. Части бывают `path` (по умолчанию), `line` и `circle`; цвета — hex или слоты палитры. Остальные поля объекта (`x`, `y`, `s`, `rot`, `alpha`, `color`, `anim`, `partAnim`) работают как у `asset`. Рисуется тем же `drawAsset`, что и модель каталога.

Круг:

```json
{"id":"moon-1","name":"Луна","kind":"shape","x":200,"y":-200,"params":{"model":{"bounds":[-40,-40,80,80],"parts":[{"id":"disk","name":"Диск","type":"circle","cx":0,"cy":0,"r":36,"fill":"#e8ecff"}]}}}
```

Путь:

```json
{"id":"star-1","name":"Звезда","kind":"shape","x":-200,"y":-240,"params":{"model":{"bounds":[-20,-20,40,40],"parts":[{"id":"star","name":"Звезда","type":"path","d":"M 0 -18 L 5 -6 L 18 -6 L 8 2 L 12 16 L 0 8 L -12 16 L -8 2 L -18 -6 L -5 -6 Z","fill":"rim"}]}}}
```

## Анимации

Периодические анимации требуют `period > 0`; `ease` у move — один из sine, inOut, out, lin. Все кадры являются функцией времени и seed.

| Поле | Тип / диапазон | По умолчанию | Описание |
|---|---|---|---|
| `from` | array; — | — | Начальное смещение [x, y]. |
| `to` | array; — | — | Конечное смещение [x, y]. |
| `t0` | number; ≥0…∞ | — | Начало в секундах. |
| `t1` | number; ≥0…∞ | — | Конец в секундах. |

## Модель каталога

Модель содержит `version`, `id`, `name`, `bounds: [x, y, width, height]` и непустой `parts`. У каждой части уникальный `id`; тип — path (по умолчанию), line или circle.

## Примеры

Минимальная сцена:

```json
{"version":1,"title":"Небо","duration":3,"palette":{"sky":["#123","#456"]},"camera":{"keys":[]},"assets":{},"layers":[]}
```

Облако:

```json
{"id":"cloud-1","name":"Облако","kind":"cloud","params":{"w":400,"h":140,"seed":1}}
```
