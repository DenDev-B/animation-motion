# Банк идей: что можно взять и откуда (комбайн для роликов)

Сюда складываем всё, что нашли в чужих проектах, видео и статьях и что можно взять для улучшения нашего комбайна. Файл живёт в репозитории как `docs/IDEAS.md`. Правило: сначала запись сюда, решение «берём» принимаем позже, при планировании этапа.

## Как вести
- Одна идея = одна строка в таблице ниже + при необходимости подробности в разделе «Заметки».
- **Лицензия** указываем обязательно. MIT/Apache/CC0 можно брать код с сохранением нотисов. «All rights reserved» или неизвестно = только идея, код переписываем сами.
- **Статус**: `идея` → `изучить` (агенту дана задача-разведка) → `берём` (в плане этапа) → `сделано` / `отказ` (с причиной).
- Всё, что скопировано в репозиторий, дополнительно записываем в `THIRD_PARTY.md` (источник, версия, лицензия, что взяли).
- Код чужих репозиториев сначала читаем, а уже потом решаем. По README мы его не оценивали.

### Предложение для этапа 0–1: сохранить три пути экспорта
- Дёшево и ничего не ломает: `engine/` не трогает `document` и `window`, а принимает контекст и размер: `renderFrame(ctx, scene, t, size)`.
- Тогда на этапе 1 остаются открытыми три пути: **A** Chrome/CDP со скриншотами (#17, без зависимостей, самый медленный), **B** Canvas в Node + поток кадров в ffmpeg (новая зависимость, нужно согласование), **C** WebCodecs (#1).
- Задача-разведка этапа 1: замерить A/B/C на ноутбуке владельца (Windows, RTX 3050 4 ГБ) на одной и той же сцене.

### Про озвучку
- Озвучка делается отдельно. Сцена и ролик ссылаются на файл дорожки; графика не зависит от голоса.
- У Timeline Studio встроенный TTS: английский (Kokoro), несколько европейских языков (Piper), китайский. Русский и украинский там не заявлены.

### Что пока не делаем
- Монтаж реальных съёмок (нарезка пауз, зумы, b-roll). Это не наше ядро: у нас графика из кода.
- Облачные генераторы фото/видео по API (WaveSpeed, RunningHub и подобные), LoRA, замена лиц: это растр и платные API, а у нас графика из кода и без платных подписок (решение владельца, 2026-10-23).
- Из методички AI-Studio и модулей автора: генерация фото и видео через облачные API (Seedream, Wan, Seedance), подмена лиц, 18+, LoRA, шаблоны промптов для ИИ-персонажа, ниши UGC-рекламы и ИИ-блогера. Растр и платные модели пока не берём.
- Аватары и lip-sync (digital human в Timeline Studio) — слишком тяжело для слабого железа и требует отдельного изучения лицензий и ответственного использования.
