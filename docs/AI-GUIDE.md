# Как сделать ролик за 5 шагов

Нужен любой чат с ИИ (Claude, Gemini, ChatGPT, бесплатные тоже подходят). Ключи и подключение сервисов не нужны: программа сама ничего не отправляет.

## 1. Напишите идею и выберите стиль
Одна-две фразы: о чём ролик, настроение, сколько сцен. Пример: «Что если бы киты летали над городом: рассвет, кит над крышами, закат». Стиль можно не выбирать; если выбрали, возьмите id из `engine/styles.ts` (warm-dusk, cold-night, noir-fog, candy-pop, ink-paper, pastel-dream).

## 2. Получите запрос на ТЗ
```
npm run ai:brief -- --idea "ваша идея" --scenes 5 --scene-seconds 8 --format 16:9 --style warm-dusk
```
Файл `out/ai/brief-prompt.md` содержит роль сценариста-режиссёра, структуру документа из 7 разделов, каталог моделей и выбранный стиль. Для Shorts используйте `--format 9:16`. В редакторе то же делает кнопка «1. Копировать запрос на ТЗ».

## 3. Получите ТЗ от ИИ
Вставьте запрос в чат. ИИ вернёт один документ Markdown в блоке ```markdown: настроение, герой, формат, локации, шоты, атмосфера и чего не хватает в каталоге. Текст и титры ИИ не планирует: их добавляют позже в видеоредакторе (например CapCut). Если ответ обрезан, напишите «продолжи с места обрыва и верни ТЗ целиком».

Сохраните ответ в файл (например `тз.md`) и проверьте:
```
npm run ai:brief-check -- тз.md --scenes 5
```
Ошибки блокируют работу, предупреждения — нет. В редакторе ТЗ вставляется в поле «2. Вставьте ТЗ от ИИ» и проверяется само.

## 4. Получите промт проекта и JSON
```
npm run ai:project-prompt -- --idea "ваша идея" --scenes 5 --scene-seconds 8 --format 16:9 --style warm-dusk --brief тз.md
```
Файл `out/ai/project-prompt.md` содержит справочник формата, каталог, ваше ТЗ и стиль (около 11 КБ без ТЗ, до 28 КБ с ТЗ). Отдайте его ИИ: он вернёт один JSON проекта в блоке кода. В редакторе это шаг «3. Копировать промт проекта».

## 5. Создайте проект
Сохраните ответ ИИ в файл (например `ответ.json`) и выполните:
```
npm run ai:apply -- ответ.json --new --name kity --brief тз.md --style warm-dusk
```
Проект появится в `projects/kity.project.json` (существующие файлы не затираются, добавляется `_2`), а ТЗ и стиль сохранятся в `meta`. В редакторе нажмите «Создать проект». Дальше — правки и экспорт:

- Правка сцены: «Копировать для ИИ» в редакторе или `npm run ai:prompt -- projects/kity.project.json --scene 2 --task "добавь дождь"`, затем `npm run ai:apply -- ответ.json --into projects/kity.project.json --scene 2`.
- Ручные правки JSON возможны в любом месте: перед сохранением всё проверяется.
- Экспорт в MP4: см. README (команда экспорта проекта).

## Если что-то пошло не так
- «Ошибка разбора JSON … ответ обрезан»: ИИ не дописал ответ.
- «Нет раздела …» или «Блок кода обрезан»: ТЗ пришло не по структуре; верните ответ целиком или попросите ИИ повторить по промту.
- «неизвестная модель каталога»: ИИ придумал id; пусть нарисует её через shape или замените на модель из списка.
- Все сцены одинаковые или пустые: уточните идею, тон (`--tone "тёплый, сказочный"`) и ТЗ.
