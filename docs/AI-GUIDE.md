# Как сделать ролик за 3 шага

Нужен любой чат с ИИ (Claude, Gemini, ChatGPT, бесплатные тоже подходят). Ключи и подключение сервисов не нужны: программа сама ничего не отправляет.

## 1. Напишите рассказ и соберите промт
Вкладка «Проект»: поле «Общий рассказ (идея ролика)», сколько сцен и секунд на сцену, формат, стиль. Кнопка «1. Копировать промт (ТЗ + проект)» кладёт в буфер всё сразу: роль режиссёра, структуру ТЗ из 7 разделов, справочник формата, каталог моделей, правила качества кадра и ваш рассказ. Через командную строку то же делает:
```
npm run ai:project-prompt -- --idea "ваша идея" --scenes 5 --scene-seconds 8 --format 16:9 --style warm-dusk --with-brief
```
Файл `out/ai/project-prompt.md` (около 16 КБ). Для Shorts используйте `--format 9:16`.

## 2. Отдайте промт ИИ и вставьте ответ
ИИ отвечает двумя блоками кода подряд: сначала ```markdown с ТЗ режиссёра, затем ```json с проектом. Вставьте ответ целиком в поле «2. Вставьте ответ ИИ» — редактор сам разделит его: ТЗ уйдёт в `meta.brief`, проект проверится, и кнопка «Создать проект» станет активной. Ответ с одним JSON (без ТЗ) работает как раньше. Если ответ обрезан, напишите ИИ «продолжи с места обрыва и верни проект целиком».

Через командную строку: сохраните ответ в файл и выполните
```
npm run ai:apply -- ответ.txt --new --name kity
```
Проект появится в `projects/kity.project.json`; существующие файлы не затираются — добавляется `_2`.

## 3. Создайте проект и правьте
Нажмите «Создать проект», дальше смотрите ролики по вкладкам: «Сцены» (правку сцен и подвкладки), «Склейка» (порядок и переходы), «Каталог» (модели). Экспорт в MP4 — см. README. Ручные правки JSON возможны в любом месте: перед сохранением всё проверяется.

## Расширенный путь: ТЗ отдельным шагом
Свёрнутый блок «Расширенно: ТЗ отдельным шагом» на вкладке «Проект» — прежний двухшаговый путь: «Копировать запрос на ТЗ» (`npm run ai:brief`, проверка `npm run ai:brief-check -- тз.md --scenes 5`), затем вставить ТЗ в поле и нажать «Копировать промт проекта с ТЗ» — на него ИИ вернёт только JSON.

## За чем следит промт качества
- Герой занимает 20–40% высоты кадра: подбираются `world.unitsPerMeter` и `params.sizeM`.
- Ночной город: `skyline` с `params.lit` 0.25–0.4 и светящимися окнами, два слоя города с разной дымкой.
- Свет рисуется объектами `glow` (фонари, фары, луна) плюс слабый отсвет на земле.
- Не меньше 6 слоёв глубины: небо, звёзды или облака, дальний и средний план, действие, передний план.
- Модели каталога предпочтительнее `shape`; недостающее рисуется 8–15 частями, а не коробкой.

## Если что-то пошло не так
- «В ответе нет JSON проекта» или подсказка «Это ТЗ, а не JSON»: вставили только документ ТЗ. Отправьте ИИ промт проекта и вставьте его ответ целиком.
- «Ошибка разбора JSON … ответ обрезан»: ИИ не дописал ответ.
- «Нет раздела …» или «Блок кода обрезан»: ТЗ пришло не по структуре; верните ответ целиком или попросите ИИ повторить по промту.
- «неизвестная модель каталога»: ИИ придумал id; пусть нарисует её через shape или замените на модель из списка.
- Все сцены одинаковые или пустые: уточните рассказ, тон (`--tone "тёплый, сказочный"`) и число сцен.
