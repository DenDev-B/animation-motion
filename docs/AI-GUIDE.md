# Как сделать ролик за 5 шагов

Нужен любой чат с ИИ (Claude, Gemini, ChatGPT, бесплатные тоже подходят). Ключи и подключение сервисов не нужны: программа сама ничего не отправляет.

## 1. Напишите идею
Одна-две фразы: о чём ролик, настроение, сколько сцен. Пример: «Что если бы киты летали над городом: рассвет, кит над крышами, закат».

## 2. Получите промт
```
npm run ai:project-prompt -- --idea "ваша идея" --scenes 5 --scene-seconds 8 --format 16:9
```
Файл `out/ai/project-prompt.md` содержит справочник формата, список моделей каталога с размерами и вашу идею (около 11 КБ). Для Shorts используйте `--format 9:16`. В редакторе то же делает блок «Новый проект из идеи».

## 3. Отдайте промт ИИ
Вставьте весь файл в чат. ИИ вернёт один JSON проекта в блоке кода (у блока в чате есть кнопка «Копировать»: нажмите её, чтобы забрать весь ответ). Текст и титры ИИ не создаёт: добавьте их позже в видеоредакторе (например CapCut). Если ответ обрезан, напишите «продолжи с места обрыва и верни JSON целиком» или попросите меньше сцен.

## 4. Примените ответ
Сохраните ответ в файл (например `ответ.json`) и выполните:
```
npm run ai:apply -- ответ.json --new --name kity
```
Проект появится в `projects/kity.project.json` (существующие файлы не затираются, добавляется `_2`). Если программа нашла ошибки, она напечатает их по-русски и создаст `out/ai/fix-request.md`: отдайте этот файл тому же ИИ, он исправит. Если ИИ предложил недостающие модели (`Предложено добавить в каталог`), добавьте их позже: нарисуйте SVG или скачайте готовый и импортируйте (`docs/IMPORT-SVG.md`).

## 5. Правки и экспорт
- Правка сцены: «Копировать для ИИ» в редакторе или `npm run ai:prompt -- projects/kity.project.json --scene 2 --task "добавь дождь"`, затем `npm run ai:apply -- ответ.json --into projects/kity.project.json --scene 2`.
- Ручные правки JSON возможны в любом месте: перед сохранением всё проверяется.
- Экспорт в MP4: см. README (команда экспорта проекта).

## Если что-то пошло не так
- «Ошибка разбора JSON … ответ обрезан»: ИИ не дописал ответ.
- «неизвестная модель каталога»: ИИ придумал id; пусть нарисует её через shape или замените на модель из списка.
- Все сцены одинаковые или пустые: уточните идею и тон (`--tone "тёплый, сказочный"`).
