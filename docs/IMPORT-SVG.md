# Импорт SVG в каталог

Как превратить готовый SVG (силуэт животного, здание, транспорт) в модель каталога. Ядро: `engine/svg-import.ts`, команда: `npm run catalog:import-svg`.

## 1. Где брать SVG

Лицензию проверяйте на странице набора перед использованием, она может меняться.

| Набор | Лицензия | Что записывать |
|-------|----------|----------------|
| Kenney | CC0 | `--license "CC0"`, автор не обязателен |
| Tabler, Lucide, Phosphor (иконки) | MIT / ISC | `--license "MIT"`, автор и источник |
| Noto Color Emoji (Google) | Apache 2.0 | `--license "Apache-2.0"`, источник |
| Game-icons.net | CC BY 3.0 | `--license "CC BY 3.0" --author "Имя автора" --attribution true` |
| Twemoji | CC BY 4.0 | то же, `--attribution true` |
| OpenMoji | CC BY-SA 4.0 | осторожно: условие share-alike, без согласования не брать |

Правила проекта: если лицензия неизвестна или «все права защищены», файл не берём. Скачивает SVG человек, скрипты ничего не качают из сети.

## 2. Команда

```
npm run catalog:import-svg -- файл.svg --id dog --name "Собака" --view side --facing right --size-m 0.6 --license "CC BY 3.0" --author "Имя" --source "game-icons.net" --url "https://..." --attribution true --tags "dog,animal,собака" --dry
```

- Обязательны: `--id`, `--view` (side, bottom, front, top, three-quarter), `--size-m`, `--license`.
- `--size-m` задаёт реальный размер в метрах; `--size-axis height|width` выбирает ось.
- `--colors keep|mono|slots`: `keep` оставляет цвета как есть (hex), `mono` красит всё одним слотом палитры, `slots` отдаёт до 4 самым частым цветам слоты палитры по яркости.
- `--dry` только проверяет и ничего не записывает в каталог.
- Для CC BY всегда ставьте `--attribution true`: автор попадёт в титры (`npm run credits`).

## 3. Что делает импорт

- Геометрия: `path` (все команды M L H V C S Q T A Z, дуги переводятся в кубические кривые), `circle`, `ellipse`, `rect` (в том числе со скруглением), `polygon`, `polyline`, `line`.
- `transform` (translate, scale, rotate, matrix, skewX, skewY, цепочки) применяется к точкам.
- Стили: атрибуты и `style="..."`: `fill`, `stroke`, `stroke-width`, `opacity`, `fill-opacity`, `stroke-opacity`; цвета `#rgb`, `#rrggbb`, `rgb()`, базовые имена, `none`, `currentColor` (по умолчанию #222222).
- Нормализация: центр в (0,0), высота bounds 200 единиц, пропорции сохраняются, ось Y вниз, как в движке.
- Каждая фигура становится отдельной частью `p1`, `p2` … (или по `id` элемента, если он подходит). Лимит: 200 частей и 200 КБ путей.

## 4. Что не поддерживается

`text`, `image`, `filter`, `mask`, `clipPath`, `use`/`symbol`, `pattern`, CSS-классы из `<style>`. Такие элементы пропускаются с предупреждением. Градиент заменяется цветом по умолчанию с предупреждением (цвет первой остановки пока не берётся).

Если SVG сложный: откройте его в Inkscape или Figma, преобразуйте текст и обводки в контуры, упростите пути, сохраните как «простой SVG».

## 5. Проверка

`npm run check:svg-import` прогоняет тестовые файлы из `tests/svg/`: валидность модели, воспроизводимость результата, предупреждения для градиента и текста, точность дуг (круг из двух дуг лежит на окружности с допуском 0,5 %).
