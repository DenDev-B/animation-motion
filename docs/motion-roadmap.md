# План по этапам: от M0 к комбайну (2026-10-22)

Принцип: каждый этап даёт то, что видно глазами и можно проверить, и не ломает предыдущий. Сначала риск (экспорт видео), потом удобство, потом контент, ИИ позже, 3D последним. Правила: кадр = функция от времени, без случайности; сцена и модели = JSON; ИИ только как необязательный слой, ручной режим работает всегда.

## Как работаем: тех лид + исполнитель
- Я пишу архитектуру и задания. Open Code (или другой агент) исполняет. Ты запускаешь, смотришь результат и возвращаешь мне.
- Репозиторий содержит `AGENTS.md` (правила для агента), `docs/ARCHITECTURE.md`, `docs/ROADMAP.md` (этот план) и `tasks/NN-имя.md`.
- Каждое задание: цель, файлы, формат JSON/интерфейсы, критерии приёмки, как проверить, что НЕ делать. Размер: до полудня работы агента.
- Цикл: задание → агент → ты запускаешь команду проверки и смотришь кадр → вы шлёте мне diff/лог/скриншот → я принимаю или правлю → следующее.
- Сложные ядра (рендер, конвертер, загрузчик моделей) я могу писать сам целиком, а агент делает интерфейс, склейку и рефакторинг.
- Правила в `AGENTS.md`: новые зависимости только по согласованию, без `Math.random`/`Date.now` в рендере, JSON-схема это контракт, один коммит на задание.

## Предварительный стек (можно поменять)
TypeScript + Vite без фреймворка (редактор на чистом TS), Node-скрипты для экспорта, ffmpeg для сборки MP4, Three.js на этапе 9.

## Решения (2026-10-22)
- Репозиторий: приватный GitHub, заведёт владелец; тех лид читает и проверяет код оттуда.
- Исполнитель: Open Code на бесплатных моделях, которые меняются по доступности, поэтому задания мелкие и подробные.
- Стек: TypeScript + Vite. Node.js и ffmpeg на ноутбуке уже стоят.
- Процесс: тех лид даёт агенту промт на составление плана, правит план, затем даёт промт на исполнение, затем проверяет результат. Часть работы может делать тех лид, если так быстрее. Приоритет: результат и экономия токенов.

## Идеи на будущее
- **Morph / пересборка (эффект):** объект распадается на части (треугольники, точки, меши) и собирается в другой объект из тех же деталей, меняя цвет и форму. Например, кошка превращается в кита. Реализация: из двух моделей берётся одинаковое число точек или треугольников (передискретизация), пары подбираются по положению или цвету, каждая часть летит по дуге с задержкой и шумом, детерминированно по seed. Работает в 2D (после этапа 4, когда есть модели) и в 3D (меши, этап 9). Если топология двух вариантов совпадает, можно морфить вершины напрямую. Параметры эффекта: длительность, разброс, задержка по частям, шум.
