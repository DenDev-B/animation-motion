# Тест MCP: «утренний лес» через Open Code

Как запустить: двойной клик по `run-mcp.bat` в корне репозитория. Он проверит сервер (`npm run mcp:ping`) и откроет Open Code в этой папке. Если Open Code не установлен: `npm install -g opencode-ai`, затем снова `run-mcp.bat`. Конфиг подключения лежит в `opencode.json`.

Вставь в Open Code этот промт целиком:

```
Ты работаешь с движком роликов animation-motion только через MCP-инструменты: get_schema, list_catalog, list_projects, validate_project, render_frame, save_project, export_video. Файлы репозитория не редактируй и команды в терминале не запускай. Поля схемы не выдумывай: если не уверен, перечитай get_schema.

Этап 0. Назови MCP-инструменты, которые тебе доступны. Если их нет, остановись и скажи об этом.
Этап 1. Вызови get_schema, list_catalog, list_projects. Одной-двумя строками: что понял про формат и что есть в каталоге.
Этап 2. Собери проект «утренний лес»: 15 секунд, 30 fps, формат 16:9. Рассвет, туман между деревьями, лучи света (kind light), несколько слоёв деревьев с параллаксом, птицы, медленное движение камеры весь ролик и crash-zoom в последние 2 секунды. Если схема даёт только один приём камеры на сцену, раздели ролик на две сцены с переходом cut. Модели каталога используй, где они подходят. Если подходящей нет, собери объект из примитивов (shape) сам и прямо скажи об этом.
Этап 3. validate_project. Исправляй, пока не будет ok.
Этап 4. render_frame в моменты 0, 7 и 14 секунд, для форматов h и v (scale 0.5). Внимательно смотри кадры. Назови три конкретные проблемы вида и исправь их, затем перерисуй те же кадры. Не больше трёх кругов правок.
Этап 5. save_project под именем forest-morning. export_video не запускай, пока я не попрошу.
Этап 6. Итоговый отчёт строго в таком виде:
1) Что получилось (2-3 строки).
2) Ошибки validate_project: полный текст каждой и как исправил.
3) Что было непонятно в схеме или в инструментах (цитатой).
4) Чего не хватило в каталоге или движке, чтобы получилось красивее (список; не выдумывай, пиши только то, на что наткнулся).
5) Какие кадры на твой взгляд всё ещё выглядят плохо и почему.
```

## Что присылать архитектору

1. Итоговый отчёт Open Code целиком (пункты 1–5).
2. Три кадра из его последнего круга (скриншоты из окна Open Code или файл `projects/forest-morning.project.json`, если он сохранился).
3. Если на этапе 0 инструментов нет: текст ошибки подключения и вывод `run-mcp.bat`.

## Как читать результат

- Много ошибок `validate_project` или выдуманные поля: не хватает подсказок в схеме и описаниях инструментов (промт).
- Деревья или птицы собраны с нуля из примитивов: не хватает моделей в каталоге.
- Ошибок нет, но кадры плоские или одинаковые: не хватает возможностей движка (свет, слои, эффекты).
