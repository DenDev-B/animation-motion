## Отклонения от задания

1. **А3: лимит 28 КБ не снижен до 24 КБ.** Условие «промт с ТЗ на 6000 символов и каталогом из 200 моделей укладывается в 24 КБ» не выполнено: 26 575 байт. По заданию оставлен 28 КБ.
2. Части А и Б были закоммичены в прошлой сессии (`8787b0e`, `7c22f52`); эта сессия сделала В и Г. Разметка блока «Расширенно: ТЗ отдельным шагом» и подпись кнопки «1. Копировать промт (ТЗ + проект)» попали в коммит 06-03b (index.html), их логика — в 06-03c.
3. Строка промта про `shape` говорила «1..10 частей» — это противоречило новому правилу «8–15 частями». Заменено на «до 15 частей» (валидатор лимит на число частей не накладывает).
4. В `tools/ai-project-prompt.ts` добавлен флаг `--with-brief`, чтобы CLI совпадал с кнопкой редактора. Новое поведение по умолчанию (без флага) не меняется.
5. Пункт В3 не оговаривал случай, когда ТЗ из ответа не проходит `validateBrief` (например нет раздела). Реализовано так: проект создаётся, ТЗ в `meta.brief` не пишется, показывается предупреждение `meta.brief`.
6. Отчёт — пятый коммит, хотя в задании «4 коммита»; отдельные файлы отчёта требует README этапа.
7. **Найдено, не исправлено** (вне задания): в обработчике «Создать проект» (`editor/main.ts`, `ideaCreate.onclick`) список `Предложено добавить в каталог` считается после `applyIdeaProject`, который очищает `ideaCandidate`, поэтому панель предложений из ИИ-ответа не показывается. Предложение из примера видят только пользователи `ai:apply` в CLI. Готов починить отдельной правкой.
8. В браузере ничего не проверялось (запрещено): статусы Б1–Б5, В3 — «не проверено»; `tools/ui-smoke.mjs` не запускался.

## Чек-лист владельца

1. Один шаг: вкладка «Проект» → написать рассказ → «1. Копировать промт (ТЗ + проект)» → вставить в любой чат ИИ → вставить ответ целиком в «2. Вставьте ответ ИИ» → «Создать проект». Проверить, что в JSON проекта на вкладке «Сцены» есть `meta.brief` и `meta.styleId`.
2. Проверить расширенный путь: развернуть «Расширенно: ТЗ отдельным шагом», скопировать запрос на ТЗ, вставить ТЗ, затем «Копировать промт проекта с ТЗ».
3. Подсказка про ТЗ: вставить в поле ответа только документ ТЗ (с заголовками «## 1.»…«## 7.») — должно написать «Это ТЗ, а не JSON. Отправьте ИИ промт проекта и вставьте его ответ сюда».
4. Вкладка «Сцены»: кнопка «+» создаёт и открывает пустую сцену; двойной клик по названию — переименование; «×» — удаление с подтверждением; на последней сцене удаление запрещено.
5. Вкладка «Склейка»: перетащить карточку сцены мышью, проверить порядок и миниатюру (кадр на 40% длительности); фокус на карточке + Alt+←/→ — тот же перенос с клавиатуры; поменять переход и его длительность между карточками; проверить общий предпросмотр.
6. Вкладка «Каталог»: увидеть новые модели `car-sport-red`, `street-lamp`, `moon`; открыть `projects/night-city-car.project.json` через «Открыть».
7. Рендер: `npm run contact -- --project projects/whale-demo.project.json` — SHA листа должен остаться `894D19CD…`.
