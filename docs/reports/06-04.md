## Отклонения от задания

1. **12 fps в тесте экспорта невозможен.** `validateProject` принимает только 24/30/60 (`fps должен быть 24, 30 или 60`),
   поэтому кратчайший легальный проект — 1 сцена × 1 с × 24 fps = 24 кадра. Меньшего разрешения тоже нет:
   `tools/export.ts` задаёт размер только форматом (1920×1080 или 1080×1920), отдельного флага разрешения нет.
2. **`import.meta.url` для пути к `tools/export.ts` не использован.** Vite собирает `vite.config.ts` во временный
   бандл, поэтому путь плагина мог указывать не на `tools/`. Вместо него у сервиса есть параметр `exportScript`
   со значением по умолчанию `<root>/tools/export.ts` — ровно то, что вызывает `npm run export`.
3. **Частичный MP4 после отмены удаляется по завершении дочернего процесса.** `child.kill()` останавливает только
   наш процесс Node; ffmpeg у него в подмастерьях дописывает файл, пока не получит EOF по stdin. Очистка
   повторяется в обработчике `close`, поэтому тест «после отмены частичный файл удалён» стабилен.
4. **`check:ui` (ui-smoke) не запускался** — запуск Chrome запрещён заданием. Правки 06-04a к `tools/ui-smoke.mjs`
   (проверка подвкладки «Загрузить») остаётся непроверенной на живом браузере; существующие требования к кнопке
   экспорта (выключена + текст `npm run export`) оффлайн-сценарий не ломает.

## Чек-лист владельца

1. `run.bat` — открыть редактор на `http://localhost:5173` (сервис `/__api/` поднимается сам в dev-режиме).
2. «Каталог → Загрузить»: перетащить 2–3 файла — один `.svg`, один `.json` и один заведомо падающий
   (например `.txt` или битый JSON). Ожидаем пофайловый список «✔ id» / «✖ причина», затем
   «Добавлено: N. Обновляю каталог…» и перезагрузку; на вопрос «Восстановить прошлую сессию?» нажать ОК —
   проект останется. При занятом id спросит «Заменить?».
3. Создать проект из ответа ИИ («Идея» → вставить ответ → «Создать проект») и у предложения нажать
   «Сохранить в каталог». Если объекта `kind: shape` с таким id/именем в проекте нет, кнопка выключена
   и подсказывает почему.
4. «Склейка» → «Экспорт MP4» → дождаться «кадр N из M» → «Готово: out/export/…», затем «Скачать MP4».
5. Во втором прогоне нажать «Отмена» — статус «Экспорт отменён, файл не сохранён», кнопка снова активна,
   новый экспорт принимается.
6. Проверить обратный сценарий: открыть тот же `dist/` без dev-сервера (или заглушить `/__api/ping`) —
   кнопки загрузки и экспорта должны остаться выключенными с подсказками про `run.bat` и `npm run export`.
