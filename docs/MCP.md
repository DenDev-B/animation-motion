# MCP-сервер движка

Сервер даёт любому MCP-клиенту (Open Code, Claude Code и др.) управлять движком: читать формат, создавать проекты, проверять их, смотреть кадры и выводить MP4. Говоришь клиенту, что хочешь, а он собирает JSON проекта и сам смотрит результат кадрами.

Запуск вручную: `npm run mcp` (протокол stdio, сам по себе ничего не печатает). Требуется Node 22, как у остального проекта; `export_video` дополнительно требует ffmpeg.

## Инструменты

| Инструмент | Что делает |
| --- | --- |
| `get_schema` | Полный формат сцены и проекта (SCHEMA-v1). Клиенту стоит прочитать его первым. |
| `list_catalog` | Модели каталога: id, название, вид, теги, размер. |
| `list_projects` | Проекты из `projects/`. |
| `validate_project` | Проверка проекта или сцены (по имени файла или JSON): ошибки с путём и подсказкой, предупреждения. |
| `render_frame` | Один кадр в PNG: `t` в секундах, `format` h/v, `scale` 0.1..1 (по умолчанию 0.5). Клиент видит картинку. |
| `save_project` | Проверяет и сохраняет в `projects/<имя>.project.json`; без `overwrite` существующий не трогает. |
| `export_video` | Выводит проект в MP4 в `out/mcp/` (долго для длинных проектов). |

Безопасность: имена проектов только из латиницы, цифр, `_` и `-` (никаких путей), запись только в `projects/` и `out/mcp/`, ключи ИИ сервер не читает.

## Подключение

Open Code, файл `opencode.json` в корне проекта:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "animation-motion": {
      "type": "local",
      "command": ["node", "tools/mcp-server.ts"],
      "enabled": true
    }
  }
}
```

Claude Code: `claude mcp add animation-motion -- node tools/mcp-server.ts` (из корня проекта).

Любой другой клиент (общий формат): `{"mcpServers":{"animation-motion":{"command":"node","args":["tools/mcp-server.ts"],"cwd":"<путь к проекту>"}}}`.

## Как просить

«Прочитай схему, посмотри каталог и сделай проект на 20 секунд: утренний лес, камера crash-zoom в конце. Покажи кадры на 0, 10 и 19 секундах, исправь, что некрасиво, и сохрани как forest-morning».
